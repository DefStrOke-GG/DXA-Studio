# DXA User Web

Пользовательский интерфейс поверх реального `dxa_project.service`. Рабочий `labeler/` не изменяется.

Возможности:

- загрузка одного или нескольких DICOM, папки перетаскиванием или ZIP-архива;
- одна стартовая лента и добавление независимых параллельных лент из текущей или новой загрузки;
- закрытие последней ленты с возвратом к исходному экрану загрузки;
- реальный GPU predict и отображение overlay модели;
- выгрузка результата в CSV или XLSX с колонками API;
- классификация и фиксация ошибок изображения;
- разметка позвоночника: межпозвонковые линии, подвздошные точки и посторонние предметы;
- разметка бедра: три анатомические точки и свободные контуры малого вертела и соседней кости;
- единая команда «Скорректировать модель»: сохранение DICOM, geometry и annotation в отдельной папке;
- скрытая очередь модельных предсказаний и видимый счётчик только ручных исправлений;
- запуск реального `POST /v1/model/partial_fit` через интерфейс.

Поддерживаются DICOM и ZIP с DICOM. Данные остаются локально в `prototype_data/`,
а хранилище API — в `dxa_project/service_data/`.

```powershell
docker compose up -d --build
```

Открыть `http://localhost:8503`.

## Работа в пользовательском веб-интерфейсе

1. На стартовом экране нажмите на карточку «Добавьте исследование» и выберите один
   или несколько DICOM либо ZIP-архив. Папку с DICOM можно перетащить прямо на
   карточку. Промежуточного окна загрузки нет.
2. Во время распознавания верхнее уведомление показывает имя текущего файла,
   позицию `N из M` и полосу фактического прогресса API. После завершения оно
   сообщает число корректно обработанных снимков.
3. В карточке снимка отображается реальный overlay модели. Если модель нашла
   нарушения, под изображением выводится их перечень понятными названиями.
4. Стрелки в заголовке переключают снимки текущего исследования. Две карточки
   справа добавляют отдельное исследование или снимок из уже загруженного набора
   для независимого параллельного просмотра.
5. Кнопка «Скачать таблицу разметки» выгружает текущий результат в CSV или XLSX.
6. Кнопка «Изменить разметку» открывает чистый снимок и инструменты для
   позвоночника или бедра. После исправления геометрии и флагов нажмите
   «Скорректировать модель»: результат сохраняется и попадает в очередь
   дообучения.
7. Для запуска дообучения требуется хотя бы один снимок, изменённый пользователем.
   Ход и результат запуска отображаются в разделе «Задания дообучения».

Та же инструкция доступна в разделе «Помощь» внутри приложения. Контакт для
вопросов: [Telegram @nsavkov](https://t.me/nsavkov).

## Дообучение

Каждое успешное предсказание автоматически попадает в скрытый набор `model`.
После ручного сохранения тот же снимок заменяется набором `human` и увеличивает
видимый счётчик. Для запуска нужен минимум один `human`; `model` в API необязателен.
Перед отправкой исключаются совпадения пикселей. API дополнительно отклоняет
validation/test-источники и их пиксельные дубликаты.

Новая версия модели после `partial_fit` не активируется автоматически. Её статус
показывается в «Заданиях дообучения», а активация validated-версии остаётся отдельной
операцией API.
