Задания дообучения

Для запуска нужен хотя бы один исправленный снимок. Модельные предсказания добавляются автоматически и используются как необязательный второй набор. Новая версия не активируется автоматически.

Настройки

Как работать с DXA Studio

  1. Добавьте исследование.Нажмите на большую карточку и выберите один или несколько DICOM либо ZIP-архив. Папку с DICOM можно перетащить прямо на карточку.
  2. Дождитесь разметки.В верхнем уведомлении показаны текущий файл и прогресс. После завершения появится число корректно обработанных снимков.
  3. Проверьте результат.Модельная разметка нанесена на снимок. Если найдены нарушения, их список показан сразу под изображением.
  4. Сравните снимки.Используйте стрелки внутри карточки. Для параллельного просмотра добавьте другое исследование или снимок из уже загруженного.
  5. Скачайте результат.Выберите CSV или XLSX рядом с кнопкой «Скачать таблицу разметки».
  6. Исправьте разметку.Нажмите «Изменить разметку», выберите область и инструменты, затем отметьте ошибки изображения. Кнопка «Скорректировать модель» сохранит исправление и добавит его в очередь.
  7. Запустите дообучение.После хотя бы одной ручной корректировки нажмите «Запустить дообучение». Состояние процесса доступно в «Заданиях дообучения».
