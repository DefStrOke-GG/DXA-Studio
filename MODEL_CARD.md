# Model card DXA Studio

## Назначение

Model bundle `final_20260929` оценивает качество однокадровых DXA DICOM поясничного отдела позвоночника и проксимального отдела бедренной кости. Он не предназначен для диагностики заболеваний.

## Состав

- маршрутизатор анатомической области — ResNet18;
- позвоночник — ResNet18 с U-Net-декодером для линий и отдельные головы для подвздошных ориентиров;
- сколиоз — отдельный ResNet18-классификатор;
- бедро — ResNet18 с U-Net-декодером для точек, ROI и маски малого вертела;
- артефакты — Faster R-CNN MobileNetV3 FPN;
- геометрические правила и калибровка порогов.

Архитектуры и исходные ImageNet-веса загружаются через `torchvision`. Итоговые веса дообучены командой на разрешённых данных проекта и распространяются отдельно от публичного репозитория. SHA256 каждого файла хранится внутри `model_manifest.json` в model bundle.

## Версионирование

Bundle должен содержать веса, `training_config.json`, `landmark_geometry_bounds.json`, `model_manifest.json`, `protocol.json` и `evaluation/calibration.json`. API копирует bundle в неизменяемую версию. Новая версия после `partial_fit` не активируется автоматически.

## Данные и оценка

Разделение train/validation/test выполняется по исследованию до аугментаций. Производные одного исследования не должны попадать в разные части. Test не используется для выбора модели или порогов. Метрики считаются отдельно по областям и типам нарушений; для малых подгрупп необходимы доверительные интервалы.

## Ограничения

- только двумерные однокадровые серые DICOM;
- результаты зависят от производителя, протокола съёмки и качества разметки;
- оценки уверенности не являются диагностическими вероятностями;
- неизвестный или технически недоступный признак должен оставаться `null`;
- перед клиническим применением нужна независимая внешняя валидация.
